## What I'm working on

### Kalopsia Web Co

At **Kalopsia Web Co**, I design and build websites and digital solutions for businesses and independent projects. This includes brochure websites, landing pages, demos, and custom web experiences tailored to each project's needs.

### FTHR Clips

**FTHR Clips** is a local-first instant replay, recording, and screenshot application for Windows and Linux. It focuses on fast capture, easy clip management, privacy, and avoiding unnecessary cloud dependencies.

- GPU-accelerated capture with platform-specific recording backends
- Replay history, manual recordings, screenshots, and clip editing
- Python/PySide6 UI with a separate native capture engine
- Windows and experimental Linux support

[Explore FTHR Clips →](https://github.com/kalopsia-space/FTHR-Clips)
